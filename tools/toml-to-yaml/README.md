# toml-to-yaml

## Description
Convert TOML (Tom's Obvious, Minimal Language) configuration files to YAML format. Useful for migrating configuration between different systems and tools.

## Usage
```tsx
import TomlToYaml from './tools/toml-to-yaml';
```

## Features
- Parse TOML with sections, arrays, and various value types
- Support for strings, integers, floats, booleans, arrays, and nested tables
- Real-time conversion as you type
- Copy output to clipboard
- Example configuration loader

## Development
```bash
npm run dev
```
