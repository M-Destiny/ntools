# csv-to-table

## Description
csv-to-table - Parse CSV data into a sortable, filterable table with pagination. Export as Markdown, JSON, or CSV.

## Usage
```tsx
import CSVToTable from './tools/csv-to-table';
```

## Features
- CSV parsing with quoted field support
- Configurable delimiter (comma, semicolon, tab, pipe)
- Optional header row detection
- Sortable columns (click header to sort)
- Filter rows by text search
- Pagination with configurable page size
- Export as Markdown table, JSON array, or CSV
- Download as .csv file

## Development
```bash
npm run dev
```
