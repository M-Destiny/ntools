# .editorconfig Generator

Generate consistent EditorConfig files for cross-editor coding style. Choose from language-specific presets or customize settings.

## Features

- **Language presets** — Default, Web, Python, Go, Rust, Minimal
- **Customizable settings** — Indentation style/size, line endings, charset, whitespace handling
- **File-type overrides** — Automatic per-language rules (e.g., 4 spaces for Python, tabs for Go/Makefiles)
- **Live preview** — See the generated output in real-time
- **Copy & Download** — Copy to clipboard or download as `.editorconfig`

## Presets

| Preset | Best For |
|--------|----------|
| **Default** | General purpose, multi-language projects |
| **Web** | JavaScript, TypeScript, HTML, CSS, JSON, YAML |
| **Python** | Python projects (4 spaces, PEP 8) |
| **Go** | Go projects (tabs, 4 width) |
| **Rust** | Rust projects (4 spaces) |
| **Minimal** | Basic settings only, no overrides |

## Why use EditorConfig?

- **Consistent style** — Same indentation, line endings, encoding across editors (VS Code, IntelliJ, Vim, Sublime, etc.)
- **No config in code** — Keeps style rules out of source files
- **Version controlled** — Commit `.editorconfig` to share style with team
- **Language aware** — Different rules for different file types automatically
