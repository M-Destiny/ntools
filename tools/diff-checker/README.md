# diff-checker

## Description
diff-checker - Compare two text blocks and visualize differences with side-by-side or unified view. Features line-by-line diff, whitespace ignore option, line numbers, and copyable diff output.

## Usage
```tsx
import DiffChecker from './tools/diff-checker';
```

## Features
- Side-by-side and unified diff views
- Line-by-line comparison with color coding
- Ignore whitespace option
- Line numbers toggle
- Load example / clear / copy diff actions
- Statistics: added, removed, unchanged lines

## Development
```bash
npm run dev
```
