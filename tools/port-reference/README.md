# port-reference

## Description
port-reference - Complete reference of TCP/UDP port numbers with service names and descriptions. Search, filter, and copy port numbers.

## Usage
```tsx
import PortReference from './tools/port-reference';
```

## Features
- Browse all standard port numbers (Well-Known 0-1023, Registered 1024-49151, Dynamic/Private 49152-65535)
- Search by port number, service name, or description
- Filter by category (Well-Known, Registered, Dynamic/Private)
- Filter by protocol (TCP, UDP, TCP/UDP)
- Copy port numbers to clipboard
- Color-coded categories and protocols for easy visual scanning
