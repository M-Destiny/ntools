# image-compressor

## Description
image-compressor - Compress images in the browser with quality control, resizing, and format conversion. Built with React + TypeScript.

## Usage
```tsx
import ImageCompressor from './tools/image-compressor';
```

## Features
- Compress JPEG, PNG, WebP, GIF, AVIF images
- Adjustable quality slider (10%-100%)
- Max width/height constraints with aspect ratio preservation
- Format conversion (Auto, JPEG, PNG, WebP)
- Drag & drop multiple files
- Side-by-side comparison (original vs compressed)
- Real-time file size statistics and savings
- Batch download all compressed images
- Client-side only - no server upload

## Development
```bash
npm run dev
```
