# json-to-markdown

## Description
json-to-markdown - Convert JSON data to readable Markdown. Supports nested objects, arrays as tables, and configurable output formatting.

## Usage
```tsx
import JsonToMarkdown from './tools/json-to-markdown';
```

## Features
- Converts JSON to Markdown with headers
- Arrays as Markdown tables
- Configurable header levels
- HTML escaping option
- Live preview
- Copy to clipboard

## Development
```bash
npm run dev
```
