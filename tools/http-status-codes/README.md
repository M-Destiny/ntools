# http-status-codes

## Description
http-status-codes - Complete reference of HTTP status codes with search, filter, and copy functionality.

## Usage
```tsx
import HttpStatusCodes from './tools/http-status-codes';
```

## Features
- Browse all HTTP status codes (1xx through 5xx)
- Search by code number, name, or description
- Filter by category (Informational, Success, Redirection, Client Error, Server Error)
- Copy code numbers to clipboard
- Color-coded categories for easy visual scanning

## Development
```bash
npm run dev
```
