# TOML to JSON

## Description
TOML to JSON - Convert TOML configuration files to JSON format with configurable indentation.

## Usage
```tsx
import TomlToJson from './tools/toml-to-json';
```

## Features
- [x] Parse TOML and convert to JSON
- [x] Configurable indentation (2 spaces, 4 spaces, minified)
- [x] Syntax highlighting for parsed structure
- [x] Copy output to clipboard
- [x] Load example TOML
- [x] Clear all inputs

## Development
```bash
npm run dev
```
