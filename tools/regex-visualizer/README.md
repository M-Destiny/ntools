# Regex Visualizer

## Description
Regex Visualizer - A powerful tool to test, debug, and visualize regular expressions with real-time highlighting and detailed explanations.

## Usage
```tsx
import RegexVisualizer from './tools/regex-visualizer';
```

## Features
- Real-time regex pattern testing with flags support (g, i, m, s, u, y)
- Visual highlighting of matches in the test string
- Detailed match information (index, length, capture groups, named groups)
- Pattern explanation with breakdown of each regex component
- Quick reference cheatsheet for common regex patterns
- Error handling for invalid regex patterns
