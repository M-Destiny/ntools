# csv-to-tsv

## Description
Convert CSV (Comma-Separated Values) data to TSV (Tab-Separated Values) format. Useful for data interchange between systems that prefer tab delimiters.

## Usage
```tsx
import CsvToTsv from './tools/csv-to-tsv';
```

## Features
- Parse CSV with quoted fields and escaped quotes
- Support for comma, semicolon, and pipe delimiters
- Real-time conversion as you type
- Copy output to clipboard
- Example data loader

## Development
```bash
npm run dev
```
