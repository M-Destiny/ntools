# TOML ↔ YAML Converter

## Description
Convert between TOML and YAML formats bidirectionally. Validates input format before converting.

## Usage
```tsx
import TomlYamlConverter from './tools/toml-yaml-converter';
```

## Features
- Bidirectional conversion (TOML ↔ YAML)
- Real-time conversion as you type
- Example data loading
- Copy to clipboard
- Error handling with descriptive messages
- Character count statistics

## Development
```bash
npm run dev
```
