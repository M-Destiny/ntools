# Markdown Linter

## Description
Markdown Linter - Lint your Markdown files with 15+ rules. Detects heading issues, spacing, formatting, and best practice violations with auto-fix capabilities.

## Usage
```tsx
import MarkdownLinter from './tools/markdown-linter';
```

## Features
- 15+ Markdown linting rules (MD001, MD003, MD004, MD007, MD009, MD010, MD012, MD013, MD018, MD019, MD022, MD025, MD031, MD033, MD034, MD040, MD041)
- Real-time linting as you type
- Auto-fix for common issues (trailing spaces, tabs, heading spacing, etc.)
- Filter by severity (errors, warnings, info)
- Copy lint report to clipboard
- Line/column positions for each issue

## Development
```bash
npm run dev
```
