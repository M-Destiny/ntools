# toml-to-xml

## Description
toml-to-xml - Convert TOML configuration to XML format. Supports tables, arrays, inline tables, and nested structures.

## Usage
```tsx
import TomlToXml from './tools/toml-to-xml';
```

## Features
- Converts TOML to well-formed XML
- Supports nested tables and arrays
- Handles inline tables
- Pretty-print option
- Copy to clipboard

## Development
```bash
npm run dev
```
