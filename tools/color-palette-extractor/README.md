# color-palette-extractor

## Description
Extract dominant color palettes from images. Upload any image to get its color palette with hex, RGB, HSL values and CSS variable exports.

## Usage
```tsx
import ColorPaletteExtractor from './tools/color-palette-extractor';
```

## Features
- Extract dominant colors from any image (PNG, JPG, WebP, GIF)
- Configurable number of colors (1-50)
- Displays hex, RGB, and HSL values for each color
- Shows percentage of image each color represents
- Copy palette as text or CSS custom properties
- Real-time preview of extracted colors

## Development
```bash
npm run dev
```
