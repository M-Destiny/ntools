# markdown-preview

## Description
markdown-preview - A live markdown editor with real-time HTML preview, syntax highlighting, and export options.

## Usage
```tsx
import MarkdownPreview from './tools/markdown-preview';
```

## Features
- Live preview with real-time updates
- GitHub Flavored Markdown support (tables, code blocks, task lists)
- Theme selection (GitHub, Light, Dark)
- Copy HTML to clipboard
- Download as .html file
- Example markdown template

## Development
```bash
npm run dev
```
