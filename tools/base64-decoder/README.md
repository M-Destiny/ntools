# base64-decoder

## Description
base64-decoder - Encode text to Base64 or decode Base64 back to text. Supports UTF-8 encoding.

## Usage
```tsx
import Base64Decoder from './tools/base64-decoder';
```

## Features
- Decode Base64 strings to plain text
- Encode plain text to Base64
- UTF-8 support
- Real-time processing
- Copy to clipboard
- Example loading
- Swap input/output

## Development
```bash
npm run dev
```
