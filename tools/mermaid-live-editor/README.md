# Mermaid Live Editor

## Description
Mermaid Live Editor - Write and preview Mermaid diagrams in real-time with support for flowcharts, sequence diagrams, class diagrams, Gantt charts, pie charts, and entity relationship diagrams.

## Usage
```tsx
import MermaidLiveEditor from './tools/mermaid-live-editor';
```

## Features
- Real-time diagram preview as you type
- Support for multiple diagram types: Flowchart, Sequence, Class, Gantt, Pie, ER
- Multiple themes: Default, Dark, Forest, Neutral
- Export diagrams as SVG or PNG
- Copy SVG to clipboard
- Load example diagrams for quick start

## Development
```bash
npm run dev
```

## Dependencies
- mermaid (loaded dynamically)
- React 19
- TypeScript
