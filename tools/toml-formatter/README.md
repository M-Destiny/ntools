# toml-formatter

## Description
toml-formatter - A useful UI tool built with React + TypeScript.

## Usage
```tsx
import TomlFormatter from './tools/toml-formatter';
```

## Features
- Format/beautify TOML with proper indentation
- Minify TOML by removing whitespace
- Validate TOML syntax with error reporting
- Load example TOML configuration
- Copy output to clipboard
- Input/output character counts

## Development
```bash
npm run dev
```
