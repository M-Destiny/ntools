# JSON to TOML

## Description
JSON to TOML - Convert JSON data to TOML format.

## Usage
```tsx
import JsonToToml from './tools/json-to-toml';
```

## Features
- [x] Parse JSON and convert to TOML
- [x] Handles nested objects and arrays
- [x] Copy output to clipboard
- [x] Load example JSON
- [x] Clear all inputs

## Development
```bash
npm run dev
```
