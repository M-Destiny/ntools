# color-scheme-generator

## Description
Color Scheme Generator - Generate harmonious color palettes from a base color using color theory principles. Export as CSS variables, Tailwind config, SCSS, or JSON.

## Usage
```tsx
import ColorSchemeGenerator from './tools/color-scheme-generator';
```

## Features
- 7 color harmony schemes: Monochromatic, Analogous, Complementary, Triadic, Tetradic, Split Complementary, Custom
- Real-time color palette generation with live preview
- Interactive base color picker (hex, RGB, HSL display)
- Custom palette builder for personalized schemes
- Multiple export formats: CSS Custom Properties, Tailwind CSS config, SCSS variables, JSON
- Copy individual colors or entire palette
- Usage examples with button styles and card components
- Color format display toggle (HEX, RGB, HSL, CSS)
