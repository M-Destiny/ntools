# regex-explainer

## Description
regex-explainer - A regular expression explainer with live matching and examples. Built with React + TypeScript.

## Usage
```tsx
import RegexExplainer from './tools/regex-explainer';
```

## Features
- Breaks down regex patterns into plain English explanations
- Live matching against test strings with highlighted matches
- Capture group extraction and display
- 10 built-in examples (email, URL, phone, IPv4, date, hex color, credit card, HTML tag, password, UUID)
- Comprehensive quick reference for regex syntax
- Support for all JavaScript regex flags (g, i, m, s, u, y, d)
- Explains anchors, quantifiers, character classes, groups, lookaround, escapes
- Copy pattern to clipboard
- Use matches as new test input
