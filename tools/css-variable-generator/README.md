# css-variable-generator

## Description
CSS Variable Generator - Generate CSS custom properties with shades and opacity variants from a single base color. Export as CSS, SCSS, Tailwind config, or JSON.

## Usage
```tsx
import CssVariableGenerator from './tools/css-variable-generator';
```

## Features
- Generate 50-950 color shades from a single base color
- Create opacity variants (10%-90%)
- Export as CSS custom properties, SCSS variables, Tailwind config, or JSON
- Live preview of generated color scale
- Copy to clipboard

## Development
```bash
npm run dev
```
