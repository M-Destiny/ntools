# CSS Grid Generator

## Description
A visual CSS Grid layout builder that lets you define grid columns, rows, gaps, and named grid areas. Supports both explicit track sizing and template areas. Copy the generated CSS for use in your projects.

## Usage
```tsx
import CssGridGenerator from './tools/css-grid-generator';
```

## Features
- Configure grid-template-columns and grid-template-rows
- Named grid template areas with visual editor
- Gap, column-gap, and row-gap controls
- Live preview of the grid layout
- One-click CSS copy

## Development
```bash
npm run dev
```
