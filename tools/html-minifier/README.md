# html-minifier

## Description
html-minifier - Minify HTML by removing whitespace, comments, and optional attributes. Supports JS/CSS minification.

## Usage
```tsx
import HtmlMinifier from './tools/html-minifier';
```

## Features
- Collapse whitespace
- Remove comments
- Remove attribute quotes (optional)
- Remove redundant attributes
- Short doctype
- Remove empty attributes
- Remove script/style type attributes
- Minify inline JavaScript
- Minify inline CSS
- Minify URLs
- Statistics panel showing compression ratio

## Development
```bash
npm run dev
```
