# sql-formatter

## Description
sql-formatter - Format and beautify SQL queries with configurable indentation, keyword casing, and layout options.

## Usage
```tsx
import SqlFormatter from './tools/sql-formatter';
```

## Features
- Configurable indentation (2 spaces, 4 spaces, tabs)
- Keyword casing (upper, lower, preserve)
- Multiple query support
- Lines between queries
- Handles major SQL keywords
- Formats CASE statements
- Handles parentheses and subqueries
- Sample query loader
- Statistics panel

## Development
```bash
npm run dev
```
