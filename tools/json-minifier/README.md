# json-minifier

## Description
JSON Minifier - Minify JSON by removing all whitespace. Validates JSON before minifying.

## Usage
```tsx
import JsonMinifier from './tools/json-minifier';
```

## Features
- Minify JSON by removing all whitespace
- Validates JSON before minifying
- Shows compression statistics
- Copy to clipboard
- Load example JSON

## Development
```bash
npm run dev
```
