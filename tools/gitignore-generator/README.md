# Gitignore Generator

Generate `.gitignore` files by selecting from 30+ curated templates for languages, frameworks, IDEs, operating systems, package managers, build tools, and testing frameworks.

## Features

- **30+ Templates** — Covers Node, Python, Go, Rust, Java, C/C++, TypeScript, React, Next.js, Vue, Svelte, Django, Flask, Laravel, VS Code, IntelliJ, Vim/Neovim, macOS, Windows, Linux, npm, yarn, pnpm, Composer, Vite, Webpack, Docker, Jest, Cypress, Playwright, Terraform, Kubernetes
- **Smart Organization** — Templates grouped by category (Languages, Frameworks, IDEs, OS, Package Managers, Build Tools, Testing, Misc)
- **Search & Filter** — Find templates quickly by name or description, filter by category
- **Multi-Select** — Choose multiple templates, combine them into one `.gitignore`
- **Live Preview** — See the generated output instantly
- **Copy & Download** — Copy to clipboard or download as `.gitignore` file
- **Default Presets** — Pre-selected popular templates (Node, macOS, Windows, Linux, VS Code)

## Usage

1. Browse templates by category or search
2. Check the templates you want to include
3. Click **Generate** to create the combined `.gitignore`
4. Copy to clipboard or download the file

## Output Format

The generated `.gitignore` includes:
- A header comment with generator info
- Each selected template wrapped in a comment block with its name and description
- Proper newlines between sections

Example:
```gitignore
# Generated by ntools Gitignore Generator
# https://github.com/M-Destiny/ntools

# Node (Node.js / npm / yarn)
node_modules/
npm-debug.log*
...

# macOS (macOS system files)
.DS_Store
.AppleDouble
...
```
