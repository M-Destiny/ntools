# css-animation-generator

## Description
CSS Animation Generator - Create custom CSS keyframe animations and transitions visually. Export production-ready CSS code with real-time preview.

## Usage
```tsx
import CssAnimationGenerator from './tools/css-animation-generator';
```

## Features
- Visual keyframe editor with live preview
- Support for both keyframe animations and CSS transitions
- 8 built-in animation presets (bounce, pulse, spin, slide, fade, shake, flip, morph)
- Configurable animation properties: duration, delay, iterations, direction, fill mode, easing
- Real-time preview of the animation
- Copy generated CSS to clipboard
- Support for transform, opacity, and background-color keyframes
- Add/remove keyframes dynamically
