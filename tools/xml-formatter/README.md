# xml-formatter

## Description
Format, beautify, and validate XML. Supports custom indentation, attribute sorting, and error detection.

## Usage
```tsx
import XmlFormatter from './tools/xml-formatter';
```

## Features
- Validates XML syntax and reports parse errors
- Configurable indentation (spaces or tabs)
- Optional attribute alphabetical sorting
- Preserves comments, CDATA, and processing instructions
- Handles self-closing tags correctly
- Copy to clipboard or download as .xml file

## Development
```bash
npm run dev
```
