# Emoji Picker

## Description
Emoji Picker - Browse, search, and copy emojis from 9 categories with 1800+ emojis. Features recent emoji history, category filtering, and instant clipboard copy.

## Usage
```tsx
import EmojiPicker from './tools/emoji-picker';
```

## Features
- 1800+ emojis across 9 categories (Smileys, People, Animals, Food, Travel, Activities, Objects, Symbols, Flags)
- Search and filter functionality
- Recent emojis saved to localStorage
- Click to copy with visual feedback
- Responsive grid layout
- Category sidebar navigation

## Development
```bash
npm run dev
```
