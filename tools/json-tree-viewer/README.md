# JSON Tree Viewer

## Description
An interactive JSON tree viewer and editor. Parse, visualize, search, and edit JSON data in a collapsible tree structure with path copying, value editing, and structural modifications.

## Usage
```tsx
import JsonTreeViewer from './tools/json-tree-viewer';
```

## Features
- Interactive collapsible tree visualization
- Real-time JSON parsing with error highlighting
- Search across keys and values with match highlighting
- Click to select nodes, double-click to edit values
- Copy JSON path or value to clipboard
- Add/remove properties and array items
- Sample JSON templates for quick testing
- Character/key count statistics
- Paste from clipboard support

## Development
```bash
npm run dev
```
