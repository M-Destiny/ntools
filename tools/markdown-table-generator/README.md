# markdown-table-generator

## Description
markdown-table-generator - Create Markdown tables visually. Adjust rows/columns, set alignments, and export to Markdown or CSV.

## Usage
```tsx
import MarkdownTableGenerator from './tools/markdown-table-generator';
```

## Features
- Visual table editor with adjustable rows and columns
- Per-column alignment (left, center, right)
- Real-time Markdown output
- Copy to clipboard
- Export to CSV
- Load example data
- Clear/reset functionality
- Live preview

## Development
```bash
npm run dev
```
