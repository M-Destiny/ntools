# YAML to CSV

## Description
Convert YAML data to CSV format. Supports custom delimiters (comma, semicolon, tab, pipe) and optional header row.

## Usage
```tsx
import YamlToCsv from './tools/yaml-to-csv';
```

## Features
- [x] Custom delimiter support (comma, semicolon, tab, pipe)
- [x] Optional header row inclusion
- [x] Proper CSV escaping for special characters
- [x] Copy to clipboard functionality
- [x] Sample data loading
- [x] Error handling with user feedback
- [x] Format hint with expected YAML structure

## Development
```bash
npm run dev
```
