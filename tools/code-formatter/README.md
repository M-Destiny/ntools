# code-formatter

## Description
code-formatter - A code beautifier and minifier for JavaScript, TypeScript, JSON, CSS, HTML, Markdown, YAML, XML, SQL, and Python. Built with React + TypeScript.

## Usage
```tsx
import CodeFormatter from './tools/code-formatter';
```

## Features
- Beautify and minify 10+ languages
- Configurable indentation (2, 4, 8 spaces)
- Auto-detect language from input
- Live formatting as you type
- Load examples for each language
- Copy/download formatted output
- Swap input/output for iterative formatting
- Character/line statistics

## Development
```bash
npm run dev
```
