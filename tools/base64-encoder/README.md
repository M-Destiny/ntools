# base64-encoder

## Description
base64-encoder - Encode text or files to Base64, decode Base64 back to text. Supports UTF-8 and binary files with file upload, copy/download output, and swap mode.

## Usage
```tsx
import Base64Encoder from './tools/base64-encoder';
```

## Features
- Encode text or binary files to Base64
- Decode Base64 back to text
- File upload support (drag & drop)
- Copy output to clipboard
- Download output as file
- Swap encode/decode modes
- Input/output character count stats
- UTF-8 safe encoding/decoding

## Development

npm run dev
