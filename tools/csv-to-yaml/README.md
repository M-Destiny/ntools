# CSV to YAML

## Description
Convert CSV data to YAML format. Supports custom delimiters (comma, semicolon, tab, pipe) and optional header row detection.

## Usage
```tsx
import CsvToYaml from './tools/csv-to-yaml';
```

## Features
- [x] Custom delimiter support (comma, semicolon, tab, pipe)
- [x] Optional header row detection
- [x] Proper YAML escaping for special characters
- [x] Copy to clipboard functionality
- [x] Sample data loading
- [x] Error handling with user feedback

## Development
```bash
npm run dev
```
