# json-diff

## Description
json-diff - Compare two JSON objects and visualize differences with color-coded output. Added (green), removed (red), changed (yellow), unchanged (gray).

## Usage
```tsx
import JsonDiff from './tools/json-diff';
```

## Features
- Compare two JSON objects side-by-side
- Visual diff with color-coded changes (added/removed/changed/unchanged)
- Nested object and array support
- Path-based difference tracking
- Show/hide unchanged values
- Statistics summary (added/removed/changed/unchanged counts)
- Real-time validation with error highlighting
