# CSS Flexbox Generator

## Description
A visual CSS Flexbox layout builder that lets you configure flex container properties (direction, justify-content, align-items, flex-wrap, gap) and manage flex items interactively. Copy the generated CSS for use in your projects.

## Usage
```tsx
import CssFlexboxGenerator from './tools/css-flexbox-generator';
```

## Features
- Configure all major flex container properties
- Add/remove flex items (1-6 items)
- Customize item size and color
- Live preview of the flexbox layout
- One-click CSS copy

## Development
```bash
npm run dev
```
